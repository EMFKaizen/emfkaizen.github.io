EMF Kaizen

LLM-powered Intelligent Assistant for Modelling & Meta-Modelling

EMF Kaizen is an Eclipse-based assistant that leverages Large Language Models (LLMs) to help users create models and meta-models in arbitrary domain-specific languages. It works at the abstract syntax level, independent of textual or graphical concrete syntaxes.

Install via Eclipse Update Site

Key Features

  • Conversational modelling assistance in natural language
  • Agnostic to the DSL and independent of concrete syntax
  • Supports both models and meta-models at any meta-level
  • Drag & drop integration of suggested fragments into EMF editors
  • Works with multiple LLM providers (OpenAI, Gemini)

How to Use EMF Kaizen

EMF Kaizen supports modelling and meta-modelling activities through an interactive, conversational workflow integrated into Eclipse. The typical usage process consists of preparing the modelling context, configuring the assistant, and requesting recommendations in natural language.

1. Start from an EMF or Ecore Project

EMF Kaizen can be used with existing EMF models or meta-models, as well as during the creation of new ones. Users typically start from an Ecore-based project or an EMF modelling workspace opened in Eclipse.

2. Configure the Meta-Model Context

Before requesting assistance, users configure the meta-model that defines the modelling language. This step provides structured context to the assistant and allows controlling which meta-model elements are exposed.

Using the Configuration Assistant, users can load a meta-model, select relevant meta-model elements, and optionally provide a natural-language description of the language.

3. Configure LLM Preferences

EMF Kaizen provides a dedicated preferences page where users configure the Large Language Model (LLM) provider and its parameters. Predefined configuration profiles are available, and advanced parameters can be adjusted if needed.

4. Request Modelling Assistance

Once the modelling context is prepared, users interact with EMF Kaizen through a chat-based interface. Requests are written in natural language and describe modelling or meta-modelling tasks, such as completing parts of a model or requesting recommendations.

The chat view is integrated with the EMF editor and the results view, allowing users to issue requests while inspecting the current model. Generated recommendations are presented separately and can be reviewed before integration.

Example of a modelling request issued through the EMF Kaizen chat view and the corresponding recommendations shown in the results view.

5. Inspect and Integrate Recommendations

Recommended model fragments can be inspected by the user before being incorporated into the target model. Integration is performed explicitly by the user through drag-and-drop actions.

This interaction model allows users to remain in control of modelling decisions while benefiting from LLM-based assistance.

Architecture Overview

EMF Kaizen is an intelligent assistant integrated into the Eclipse environment to support modelling and meta-modelling activities based on the Eclipse Modeling Framework (EMF). The architecture is designed to combine conversational interaction with structured model manipulation.

The architecture is organised into three main parts. A configuration component allows users to select and describe meta-models and to configure the Large Language Model (LLM) used by the assistant. A modelling-assistance component provides a chat-based interface for formulating natural-language requests and receiving model recommendations. A session and result management component handles the processing, storage, and integration of generated model fragments.

Natural-language requests are transformed into structured prompts that incorporate the current model, its meta-model, and the interaction history. The selected LLM generates model fragments that can be inspected and incorporated into the target model through the EMF editor.
