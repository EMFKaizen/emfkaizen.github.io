EMF KAIZEN

LLM-powered Intelligent Assistant for Modelling & Meta-Modelling

EMF Kaizen is an Eclipse-based intelligent assistant designed to support modelling and meta-modelling activities through the integration of Large Language Models (LLMs). The assistant operates at the level of abstract syntax and is independent of textual or graphical concrete syntaxes, enabling its application across heterogeneous modelling languages.

Install via Eclipse Update Site

Key Features

  • Natural-language assistance for modelling and meta-modelling tasks
  • Operation over abstract syntax, independent of concrete syntaxes
  • Support for models and meta-models at arbitrary meta-levels
  • User-controlled integration of generated recommendations
  • Compatibility with multiple LLM providers (e.g., OpenAI, Gemini)

Usage Overview

EMF Kaizen supports an iterative modelling workflow fully integrated into the Eclipse IDE. The interaction process consists of preparing the modelling context, configuring the assistant, and requesting modelling support using natural language.

1. Start from an EMF or Ecore Project

Users begin by opening an existing EMF model or meta-model, or by creating a new Ecore-based project. EMF Kaizen directly analyses and manipulates the abstract syntax of the loaded models.

2. Configure the Meta-Model Context

Before requesting modelling assistance, the assistant must be explicitly configured with respect to the target modelling language. This configuration constrains the assistant to the relevant subset of the meta-model and provides the structured context required for semantically grounded recommendations.

The configuration process is performed through a dedicated Configuration Assistant, which guides the user through three consecutive steps.

Configuration Assistant workflow. Top: loading the target meta-model and selecting the relevant meta-model elements. Bottom: providing or generating a natural-language description of the modelling language used to enrich the structured context passed to the LLM.

3. Configure LLM Preferences

EMF Kaizen provides a dedicated preferences page that allows users to select the LLM provider and configure inference parameters such as model choice, request limits, and advanced reasoning options.

Preferences page for selecting the LLM provider and configuring model-specific inference parameters.

4. Request Modelling Assistance

Once the modelling context has been configured, users interact with the assistant through a conversational interface integrated into Eclipse. Modelling requests are expressed in natural language and may describe completion, refinement, or extension tasks over the current model.

Natural-language modelling request issued through the EMF Kaizen chat interface, triggering the generation of structured modelling recommendations.

5. Inspect and Integrate Recommendations

Generated recommendations are presented in a dedicated results view. Users can inspect the proposed model fragments and explicitly integrate selected elements into the target model via drag-and-drop operations.

Inspection of generated model fragments and user-controlled integration into the target model using drag-and-drop.

Architecture Overview

EMF Kaizen is architected as a set of Eclipse-integrated components that separate conversational interaction, configuration management, prompt construction, and result integration. This modular architecture enables flexible integration with different LLM providers and modelling languages.

High-level architecture of EMF Kaizen, illustrating its integration with Eclipse, external LLM providers, and EMF-based modelling environments.

Research Context

EMF Kaizen is developed as part of an ongoing academic research effort exploring the integration of Large Language Models with Model-Driven Engineering environments.
