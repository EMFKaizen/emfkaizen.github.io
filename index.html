EMF Kaizen

LLM-powered Intelligent Assistant for Modelling & Meta-Modelling

EMF Kaizen is an Eclipse-based conversational assistant that leverages Large Language Models (LLMs) to support modelling and meta-modelling tasks across arbitrary domain-specific languages. The assistant operates at the abstract syntax level and is independent of any textual or graphical concrete syntax.

Install via Eclipse Update Site

Key Features

  • Natural-language assistance for modelling and meta-modelling
  • Abstract-syntax-level operation (syntax independent)
  • Support for arbitrary EMF-based domain-specific languages
  • User-controlled integration via drag-and-drop
  • Multiple LLM providers (OpenAI, Gemini)

Usage Workflow

EMF Kaizen supports an iterative workflow integrated into Eclipse, combining explicit configuration of modelling context with conversational modelling assistance.

1. Start from an EMF or Ecore Project

Users work on an existing EMF model or meta-model, or create a new Ecore-based project. EMF Kaizen operates directly on the abstract representation of the model.

2. Configure the Meta-Model Context

The Configuration Assistant enables language engineers to define the modelling context provided to the LLM by selecting relevant meta-model elements and optionally providing a natural-language description.

Step 1 – Loading the target meta-model.

Step 2 – Selecting relevant meta-model elements.

Step 3 – Editing or generating a natural-language description.

Complete Configuration Assistant workflow.

3. Configure LLM Preferences

Users configure the LLM provider, model variant, predefined profiles, and advanced inference parameters through a dedicated preferences page.

LLM preferences configuration page.

4. Request Modelling Assistance

Modellers interact with EMF Kaizen via a chat-based interface, issuing natural-language requests for completion, refinement, or explanation.

Natural-language modelling request and generated recommendations.

5. Inspect and Integrate Recommendations

Recommendations are presented as structured model fragments that can be inspected and selectively integrated into the active model via drag-and-drop.

User-controlled integration of generated fragments.

Architecture Overview

EMF Kaizen is structured into configuration, modelling-assistance, and session-management subsystems, tightly integrated with Eclipse and EMF editors.

High-level architecture of EMF Kaizen.

Research Context

EMF Kaizen is an ongoing research project developed at the Universidad Autónoma de Madrid (UAM), exploring the integration of Large Language Models with Model-Driven Engineering environments.
