Install EMF Kaizen via Eclipse Update Site

Follow the steps below to install EMF Kaizen into your Eclipse IDE using the official update site.

Open Update Site URL ← Back to Home

Installation Instructions

  1. Open Eclipse.
  2. Go to Help → Install New Software…
  3. Click Add... to define a new update site.
  4. In the Location field, paste the following URL:
    https://emfkaizen.github.io/updatesite/
  5. Press OK. Eclipse will fetch the available features.
  6. Select EMF Kaizen from the list of available software.
  7. Click Next, review the installation details, and then click Next again.
  8. Accept the license agreement and click Finish.
  9. If Eclipse shows a security warning about unsigned content, confirm to continue.
  10. Restart Eclipse when prompted.

Update Site URL

You can always use the following URL to re-install or update EMF Kaizen:

https://emfkaizen.github.io/updatesite/
